1  Vector Spaces

These notes and exercises follow Axler (2024). Throughout, \(\mathbb{F}\) is a field (usually \(\mathbb{R}\) or \(\mathbb{C}\)).

1.1 Definition of a vector space

Definition 1.1 (Addition) An addition on a set \(S\) is a binary operation

\[ +:S\times S\to S,\qquad(s,t)\mapsto s+t. \]

Definition 1.2 (Scalar multiplication) A scalar multiplication on \(S\) over \(\mathbb{F}\) is a map

\[ \mathbb{F}\times S\to S,\qquad(\lambda,s)\mapsto\lambda s. \]

Definition 1.3 (Vector space) A vector space \(V\) over \(\mathbb{F}\) is a set equipped with an addition (Definition 1.1) and scalar multiplication (Definition 1.2) satisfying the following properties:

  • Commutativity: for all \(u,v\in V\), \(u+v=v+u\).

  • Associativity: for all \(u,v,w\in V\), \((u+v)+w=u+(v+w)\).

  • Additive identity: there exists \(0\in V\) such that \(v+0=v\) for every \(v\in V\).

  • Additive inverse: for every \(v\in V\), there exists \(w\in V\) such that \(v+w=0\).

  • Multiplicative identity: for every \(v\in V\), \(1v=v\).

  • Associativity of scalar multiplication: for all \(a,b\in\mathbb{F}\) and \(v\in V\), \(a(bv)=(ab)v\).

  • Distributive laws: for all \(a,b\in\mathbb{F}\) and \(v,w\in V\),

    \[ a(v+w)=av+aw,\qquad(a+b)v=av+bv. \]

Source correction. The LaTeX list omitted associativity of scalar multiplication; it is included above. The scalar and vector names in the distributive laws have also been made consistent.

Theorem 1.1 (Unique additive inverse) For every \(v\in V\), there exists a unique \(w\in V\) such that \(v+w=0\).

TipProof

Suppose \(V\) is a vector space. Let \(v\in V\). Existence follows from the additive inverse axiom in Definition 1.3. Suppose \(w\) and \(w'\) are additive inverses of \(v\). Then

\[ w=w+0=w+(v+w')=(w+v)+w'=0+w'=w'. \]

Thus \(w=w'\).

Remark. We just proved a statement of the form

\[ \forall v\in V,\quad [\exists u\in V,\ v+u=0]\ \land [\forall w,w'\in V,\ ((v+w=0)\land(v+w'=0))\implies w'=w]. \]

Although this makes the proof look more complicated than it is, it demonstrates what is going on under the hood. Given any vector \(v\), we must show that both statements are true. For the first, the definition of a vector space provides an inverse \(u\). For the second, we choose two inverses \(w,w'\) and use the vector-space properties to show that they are the same. The existence part comes from the axiom; the uniqueness argument alone does not prove existence. We denote this unique inverse by \(-v\).

Theorem 1.2 (Zero times a vector) For every \(v\in V\), \(0v=0\).

TipProof

For \(v\in V\), we have

\[ 0v=(0+0)v=0v+0v. \]

Adding the additive inverse of \(0v\) to both sides leaves \(0=0v\), as desired.

theorem zero_smul_eq_zero : ∀ v : V, (0 : ℝ) • v = 0 := by
  intro v
  have h : (0 : ℝ) • v = (0 : ℝ) • v + (0 : ℝ) • v := by
    nth_rewrite 1 [← add_zero (0 : ℝ)]
    rw [add_smul]
  have h2 : (0:ℝ) • v + -((0:ℝ) • v) = ((0:ℝ) • v + (0:ℝ) • v) + -((0:ℝ) • v) := by
    rw [← h]
  rw [add_neg_cancel] at h2
  rw [add_assoc, add_neg_cancel, add_zero] at h2
  rw [h2]

1.2 Exercises

Exercise 1.1 (Double additive inverse) Prove that \(-(-v)=v\) for every \(v\in V\).

TipSolution

Suppose \(v\in V\), where \(V\) is a vector space. By definition, \(-v\) is the additive inverse of \(v\), so

\[ v+(-v)=0. \]

Also by definition, the additive inverse of \(-v\) satisfies

\[ (-v)+(-(-v))=0. \]

Using commutativity (Definition 1.3), we can rearrange the first expression to see that

\[ \begin{aligned} (-v)+v&=0,\\ (-v)+(-(-v))&=0. \end{aligned} \]

Now Theorem 1.1 gives \(-(-v)=v\).

NoteLean

The source formalization of Exercise 1.1. This statement only uses the additive-group structure; no scalar multiplication is needed. The displayed snippet omits the source’s shared Mathlib imports and variable declarations; the original playground provides them.

theorem double_negation (v : V) : -(-v) = v := by
  have h1 : v + (-v) = 0 := add_neg_cancel v
  have h2 : (-v) + (-(-v)) = 0 := add_neg_cancel (-v)
  rw [add_comm] at h1
  -- h1 : -v + v = 0
  -- h2 : -v + -(-v) = 0
  have := add_left_cancel (h1.trans h2.symm)
  exact this.symm

Exercise 1.2 (Replacing the additive inverse axiom) Show that in Definition 1.3, the additive inverse condition can be replaced with the condition

\[ \forall v\in V,\qquad 0v=0. \]

TipSolution

We need to show that the following are equivalent with the help of the other vector-space axioms:

  1. For every \(v\in V\), there exists \(w\in V\) such that \(v+w=0\).
  2. For every \(v\in V\), \(0v=0\).

(a) \(\Rightarrow\) (b). Assume all the axioms, including additive inverses. This direction is Theorem 1.2.

(b) \(\Rightarrow\) (a). Assume the remaining axioms and \(0v=0\) for every \(v\in V\). For a given \(v\), take \(w=(-1)v\), which exists by scalar multiplication. Distributivity and \(1v=v\) give

\[ v+w=1v+(-1)v=(1+(-1))v=0v=0. \]

Thus \(w\) is an additive inverse of \(v\).

Source correction. We construct \(w\) as \((-1)v\), not as \(-v\): the existence of a vector additive inverse is what this direction must prove. The forward direction uses the zero-scalar theorem, rather than inverse uniqueness.

NoteLean

The original snippet associated with Exercise 1.2 is preserved below. Its context already assumes [AddCommGroup V] [Module ℝ V], so this is not a formal proof of the weaker axiom system used in the exercise. It proves the displayed equivalence inside an existing module. Its reverse implication uses zero_smul_eq_zero from the zero-scalar Lean block; that dependency is included in the original playground.

theorem add_inv_swap : ∀ v : V, ((0 : ℝ) • v = 0 ↔ ∃ w : V, v + w = 0) := by
  intro v
  constructor
  · intro h
    use (-1 : ℝ) • v
    nth_rewrite 1 [← one_smul ℝ v]
    rw [← add_smul]
    rw [show (1 + -1 : ℝ) = 0 from by ring]
    rw [h]
  · intro h
    exact zero_smul_eq_zero v
